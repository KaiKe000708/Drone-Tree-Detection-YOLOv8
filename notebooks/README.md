# Notebook de treino

[`treino_yolov8_arvores.ipynb`](treino_yolov8_arvores.ipynb): fine-tuning do YOLOv8m no Google Colab (GPU T4), da instalação até a exportação para ONNX.

Para rodar, faça o upload do `.zip` do dataset exportado do Roboflow (formato YOLOv8/v9). O dataset não é público, porque são dados de uma propriedade privada.
